# Breast-cancer-classification


🧬 Breast Cancer Classification using Neural Networks

A deep learning project that leverages Artificial Neural Networks (ANNs) to classify breast tumors as benign or malignant, helping in early detection and diagnosis of breast cancer.

📌 Project Overview

Breast cancer is one of the most common cancers worldwide. Early detection significantly improves survival rates, and machine learning can play a vital role in assisting medical professionals.

In this project, I built a Neural Network classifier that takes diagnostic features extracted from breast tissue samples and predicts whether the tumor is benign (non-cancerous) or malignant (cancerous).

🚀 Key Features

✅ Binary classification (Benign vs Malignant)

✅ Built using Artificial Neural Networks (ANNs)

✅ Achieved high accuracy with optimized architecture

✅ Data preprocessing (scaling, normalization, train-test split)

✅ Evaluation using accuracy, confusion matrix, and classification report

🛠️ Tech Stack

Python 3

TensorFlow / Keras

Pandas, NumPy

Scikit-learn

Matplotlib, Seaborn (for visualization)

📊 Dataset

Source: Breast Cancer Wisconsin Dataset (UCI ML Repository)

Features: Cell nuclei characteristics (radius, texture, smoothness, compactness, etc.)

Target:

0 → Malignant

1 → Benign

🔬 Model Architecture

Input Layer: Features from dataset

Hidden Layers: Dense layers with ReLU activation

Output Layer: Sigmoid activation for binary classification
